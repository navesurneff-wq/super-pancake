LIFE TRACKER — VERSION SANS ONGLET ARGENT

Cette version ne contient aucun onglet Argent, Finance ou Budget.

INSTALLATION :
1. Décompresser cette archive.
2. Remplacer TOUS les fichiers à la racine du dépôt GitHub par le contenu de super-pancake-main.
3. Vérifier que index.html, app.js, style.css et sw.js sont bien remplacés.
4. Attendre la fin du déploiement GitHub Pages.
5. Sur iPhone : fermer l'application web, puis la rouvrir. Si l'ancien écran persiste, ouvrir le site dans Safari, actualiser la page, puis réinstaller le raccourci sur l'écran d'accueil.

La version conserve la clé de stockage existante afin de préserver les données locales.
